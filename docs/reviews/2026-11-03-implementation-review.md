# Implementation review

Claude Opus implemented the six-rule analyzer from a bounded contract. A separate GPT reviewer wrote 49 behavioral holdouts without reading the implementation, then four supplemental controls based on disclosed limitations. The supplemental controls reproduced false positives for approval invitations/questions and unrelated loan-copy durations. A separate implementation agent corrected those behaviors. Independent rerun: all 53 holdouts pass.

Claude Sonnet then reviewed the API, models, and UI as a read-only integration review. It found no defect in the core revision/decision invariants, workspace scoping, manual concerns, or React text rendering. Actionable follow-ups were integrated: production requires the exact WEB_ORIGIN, the browser workspace cookie lasts seven days, 404 responses use the shared error format, and the revision editor no longer presents older feedback as current.

Root verified local submission revision, clean self-check, comparison, and exact-revision approval in the browser. The combined suite passed 83 tests, Deno and Next type checks, and the Next production build before hosted verification. Hosted verification then exposed a PostgreSQL-driver JSON serialization difference that local PGlite tests did not catch; release verification remains open until that regression and the deployed workflow pass.

Hosted follow-up: the JSONB parameter encoding defect was reproduced against Neon and corrected with explicit text-to-jsonb casts. A real Neon creation/revision/seeding probe passed. Local coverage grew to 85 passing tests with seed failure/recovery regressions. `node scripts/smoke.mjs https://clearpath-review-psi.vercel.app` passed the deployed workflow through the frontend proxy, including version conflicts and separate visitor isolation. Initial demo seeding took 11.7 seconds; parallel seeding is being evaluated as a final performance refinement.

The regulatory paragraph labels in the analyzer were checked against the current [CFPB §1026.16 text](https://www.consumerfinance.gov/rules-policy/regulations/1026/16/): introductory labeling is paragraph (g)(3); promotional-period/later-rate text is (g)(4); the linked-banner exclusion applies to (g)(4) under (g)(5). The application evaluates a bounded text subset and does not certify regulatory compliance.
