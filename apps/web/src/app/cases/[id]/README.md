# Submission workspace

Route: `/cases/[id]`

This is where the review loop happens. Keeping copy, references, evidence, and feedback together reduces repeated reading and separate email exchanges.

**Reviewers** inspect the current revision, confirm or dismiss automated concerns, add manual concerns, and request changes or approve copy. **Submitters** see the recorded requests beside the editor and return a new revision.

Comparisons highlight copy and context changes. Checks rerun across the whole revision, with earlier judgments available as history.

Optional AI compliance and marketing opinions stay attached to the revision they analyzed. They cannot approve copy. The decision history records what was reviewed and why.
