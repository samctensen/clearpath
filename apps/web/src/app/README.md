# Dashboard

Route: `/`

The dashboard answers **what needs attention next?** Each role sees the work it can move forward.

- **Reviewer:** a review map and queue show current status and target dates, with a direct path into the next review.
- **Submitter:** a reason chart groups missing information and recorded reviewer requests. Selecting a reason filters the queue and shows matching feedback, with direct links to add information or revise the submission.

Chart counts describe submissions, not severity. Reasons can overlap; the headline total counts each submission once.

Returning from a case preserves queue context so users can continue their work.
