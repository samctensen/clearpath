# Offer library

Route: `/catalog`

Both roles need the same reference for what ClearPath actually offers.

The library presents fictional credit-card, personal-loan, and mortgage-prequalification offers, with their terms, versions, applicable context, and example copy. Users can start a submission from an example or consult the terms while reviewing a claim.

A versioned offer makes comparisons concrete: a rate or promotional period is checked against the selected offer rather than a universal rule. Examples are starting points; adapting one does not transfer approval to the new submission. Offer administration is outside this demo.
