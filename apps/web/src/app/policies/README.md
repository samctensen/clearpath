# Policy guide

Route: `/policies`

The guide makes the automated checks understandable to both submitters and reviewers.

Each check explains its purpose, applicability, reference, and limits. Product references, regulatory references, and fictional company policy are distinguished so users can understand the basis for a concern.

The six checks cover review context, offer consistency, introductory-rate labels, card promotional terms, personal-loan repayment claims, and approval claims. Missing context remains uncertainty rather than silently passing a check.

This is a bounded explanation of the demo's review logic, not an exhaustive compliance rulebook. The same guidance supports preparing copy and assessing it.
