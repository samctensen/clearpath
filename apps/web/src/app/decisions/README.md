# Decision log

Route: `/decisions`

A decision should be understandable after the conversation has moved on.

The log keeps copy approvals and change requests tied to their recorded revision, feedback, and reference context. Reviewers can search and filter the history, inspect the saved copy, and open the corresponding revision when the case remains available.

Historical records stay distinct from the current queue. A later edit does not rewrite an earlier decision. This makes the review outcome traceable without reconstructing an email thread.
